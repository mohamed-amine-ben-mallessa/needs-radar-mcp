# Assets

## `demo.gif` — how to record it

The README references `assets/demo.gif`: a short screen recording of **Claude Code**
using this MCP (e.g. running `/needs-radar:scan developers in Lyon` and showing the
ranked prospect list). To create it:

1. Install the plugin in Claude Code (see the main README) so the `needs-radar` tools are live.
2. Run a clean, photogenic query — e.g. *"Scan companies hiring developers in Lyon and give me the top prospects."*
3. Record the terminal with a GIF tool:
   - [`vhs`](https://github.com/charmbracelet/vhs) (script a terminal demo to GIF), or
   - [`asciinema`](https://asciinema.org) + [`agg`](https://github.com/asciinema/agg), or
   - any screen-to-GIF recorder (ScreenToGif, Kap, Peek).
4. Keep it **under ~8 seconds** and **≤ 5 MB**.
5. Save it here as `demo.gif`.

Until the GIF exists, GitHub shows a broken-image placeholder — replace it with the recording.
